**Task No.1 (Bank Marketing**)
This project is about figuring out if a bank customer will sign up for a term deposit after a marketing campaign. The project started with the UCI Bank Marketing dataset. The data had to be changed so it could be used. This meant turning categories into numbers. It was done using one- encoding. This resulted in 51 features.
Two models were used to make predictions. These were Logistic Regression and Random Forest. The project compared these two models to see which one was better.The models had to be tested to see if they were accurate. This was done using Confusion Matrices and ROC Curves. The reason for this was that the data was not balanced. There were more people who did not sign up for a term deposit than those who did.To be clear, about how the models made decisions LIME was used. It was used to look at five predictions. It showed which features were important. These features included how long a call was or if a previous campaign was successful.The term deposit project shows how machine learning works. It starts with getting and preparing the data. Then it moves on to making the models and explaining how they work. This is done using Explainable AI to understand how customers behave. The project uses the term deposit to see how customers will react to marketing campaigns.


**Task No.2 (Customer Segmentation)**
This project uses the Mall Customers dataset to find types of shoppers and create marketing plans just for them. I started by looking at the data to see how old shoppers are, how much they earn and how much they spend. I used  K-Means clustering to group shoppers together.Which helped me find out that there are five groups of shoppers.To make it easier to understand  I used Principal Component Analysis or PCA.It helped see the groups in a way on a graph with just two lines.
These groups are really different from each other. Some shoppers earn a lot. Spend a lot while others are careful with their money.By looking at what makes each group special I came up with marketing ideas that will work best for each one.
This shows how helpful it can be to use data to make business decisions.The Mall Customers dataset helped me understand how to sell to kinds of shoppers.Looked at age, income and spending scores to see what shoppers are like.The K-Means clustering and PCA helped in finding and visualizing the groups.The groups are high-income shoppers, budget-conscious shoppers and three others.This project demonstrates the power of data analysis, in driving business decisions.It shows how to use data to create targeted marketing strategies.
