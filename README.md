**Task No.1 (Bank Marketing**)
This project is about figuring out if a bank customer will sign up for a term deposit after a marketing campaign. The project started with the UCI Bank Marketing dataset. The data had to be changed so it could be used. This meant turning categories into numbers. It was done using one- encoding. This resulted in 51 features.

Two models were used to make predictions. These were Logistic Regression and Random Forest. The project compared these two models to see which one was better.

The models had to be tested to see if they were accurate. This was done using Confusion Matrices and ROC Curves. The reason for this was that the data was not balanced. There were more people who did not sign up for a term deposit than those who did.

To be clear, about how the models made decisions LIME was used. It was used to look at five predictions. It showed which features were important. These features included how long a call was or if a previous campaign was successful.

The term deposit project shows how machine learning works. It starts with getting and preparing the data. Then it moves on to making the models and explaining how they work. This is done using Explainable AI to understand how customers behave. The project uses the term deposit to see how customers will react to marketing campaigns.
